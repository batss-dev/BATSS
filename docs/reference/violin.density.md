# Violin plot density estimates

Extracts density estimates for a violin plot.

## Usage

``` r
violin.density(data, h = NULL)
```

## Arguments

- data:

  data vector.

- h:

  a scalar corresponding to the smoothing parameter.

## Value

a list of coordinates and corresponding density values.
