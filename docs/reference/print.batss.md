# Print function for BATSS outputs

Print method function for objects of class 'batss' (i.e., output of the
function [batss.glm](batss.glm.md)).

## Usage

``` r
# S3 method for class 'batss'
print(x, ...)
```

## Arguments

- x:

  An object of class 'batss'.

- ...:

  Additional arguments affecting the print produced.

## Value

Prints information for objects of class 'batss'.

## See also

[`batss.glm()`](batss.glm.md), the function generating S3 objects of
class 'batss'.
